## Stack — decided, do not re-litigate

| Concern | Choice | Why |
| --- | --- | --- |
| Build | **Vite + React 19 + TypeScript** | Fastest path to a static bundle; no SSR need and no Next.js container complexity for a compose file the judges must run. |
| Styling | **Tailwind CSS v4**, CSS-first `@theme` | The token block in `VISUAL_LANGUAGE.md` §10 pastes straight in. |
| Components | **none — hand-built** | Every component library's defaults are the look we are explicitly avoiding. The component set here is about a dozen elements; a library costs more than it saves. **Do not add shadcn/ui, MUI, Chakra, or daisyUI.** |
| Icons | **lucide-react** | Matches the reference's line-icon weight. 18px in nav and buttons, 16px in chips. |
| Charts | hand-rolled SVG for the donut, the bars, and the confidence bars; **recharts** only for a sensor time-series | The donut is ~40 lines of SVG and gets the reference's exact segment gaps; a chart library cannot. |
| Routing | **react-router v7**, declarative | Seven routes. |
| Server state | plain `fetch` in a typed `src/api/client.ts` + a small `useRequest` hook | Seven screens, no cache invalidation problem worth a library. Add TanStack Query only if a real need appears. |
| Forms | React state | One form. |
| Dates | `Intl.DateTimeFormat` with `id-ID` | No date library. |

`AGENTS.MD` posture applies: the laziest solution that actually works,
stdlib/native first, delete over add.

## Layout

```
frontend/
├── index.html                 fonts + root
├── src/
│   ├── index.css              @theme tokens (VISUAL_LANGUAGE §10)
│   ├── main.tsx  App.tsx      router
│   ├── api/
│   │   ├── client.ts          fetch wrapper: identity headers, error envelope → typed error
│   │   └── types.ts           mirrors ../API.md — the only place API shapes are declared
│   ├── shell/                 AppShell, NavRail, Header, StatusCard
│   ├── ui/                    Card, MetricCard, Badge, Button, Input, DropZone,
│   │                          Table, Dot, StateTrack, Donut, Bars, Tooltip, Skeleton
│   ├── screens/               Setup, Analyze, AnalysisResult, WorkOrders,
│   │                          WorkOrderDetail, Execute, Report, Compare
│   └── lib/                   format.ts (Rp, dates, tabular), severity.ts (score → token)
├── Dockerfile                 build → nginx, proxies /api to the backend
└── vite.config.ts             dev proxy /api → http://localhost:8000
```

`api/types.ts` is generated by hand from `../API.md` and is the single place API
shapes live. No inline `any`, no shapes inferred from a console log.
